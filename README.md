# АвтоПлан 2.7.0

Тестовая release-candidate сборка Telegram Mini App для автомобилистов.

## Что исправлено в 2.7.0

- Кнопка `Пробег` переименована в `Текущий пробег`.
- Добавлено ненавязчивое предложение обновить пробег при входе: не чаще одного раза в день; после успешного ввода повторный запрос в этот день не показывается.
- Кнопка пробега получает аккуратный визуальный акцент, если данные давно не обновлялись.
- В разделе `Штрафы` исправлена иконка водительских прав.
- Добавлена загрузка фото водительского удостоверения с OCR; распознанные данные можно проверить и исправить перед сохранением.
- Исправлен интерфейс быстрых запросов в разделе `Запчасти`: названия видны сразу.
- Улучшен поиск запчастей: проверяются не только названия узлов, но и названия/артикулы деталей внутри применимых узлов конкретной модификации.
- Убраны технические идентификаторы узлов/модификаций из пользовательского интерфейса.
- В результатах деталей показываются название, бренд, артикул и применимость к выбранной модификации.
- Добавлен отдельный экран проверки цены. Цена не выдумывается: без подключённого ценового провайдера показывается актуальный поисковый запрос. Для production можно подключить `PARTS_PRICE_URL`.
- Сообщества теперь автоматически создаются/обеспечиваются по паре `марка + модель`; сообщение больше не должно требовать от пользователя технический `communityId`.
- Поиск сообществ поддерживает распространённые русские названия моделей, включая `Калина`.
- Добавлены регрессионные тесты для всех перечисленных исправлений.

## Перед запуском в Telegram

Production Mini App должен быть размещён на HTTPS-адресе. Telegram официально поддерживает запуск Mini Apps из профиля бота, кнопки меню и прямой ссылки; для production нужно использовать HTTPS. urlДокументация Telegram Mini Appshttps://core.telegram.org/bots/webapps

Минимально необходимая конфигурация:

```text
TELEGRAM_BOT_TOKEN=...
MINI_APP_URL=https://ваш-домен.example
```

Для карты:

```text
YANDEX_MAPS_JS_API_KEY=...
YANDEX_SEARCH_API_KEY=...
```

Для реальных штрафов нужен отдельный официальный/лицензированный провайдер:

```text
FINES_API_URL=...
FINES_API_TOKEN=...
```

Для каталога запчастей сейчас используется FAPI demo API. Публичный demo-ключ предназначен для оценки и имеет общую квоту; для постоянной production-нагрузки нужен персональный ключ. FAPI документирует подбор aftermarket-запчастей по марке/модели/модификации/узлу, VIN и кроссы аналогов. urlСпецификация FAPI Catalog APIhttps://github.com/fapi-dev/catalog-openapi

Для автоматических цен нужен отдельный ценовой провайдер. Пока приложение намеренно не показывает выдуманную «среднюю цену».
